Lineage & locus config
----------------------

Configuration of the sampled lineages and of the loci. A :class:`~phasegen.lineage.LineageConfig` specifies the number of lineages sampled in each population, and a :class:`~phasegen.locus.LocusConfig` specifies the number of loci, the recombination rate between them and the number of lineages that are initially unlinked.
